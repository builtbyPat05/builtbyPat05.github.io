# Patrick Taylor — Portfolio

Personal portfolio hosted at https://builtbyPat05.github.io/ using GitHub Pages.

## Edit

The complete website is in `index.html`. It uses HTML and CSS with no build step,
external fonts, tracking scripts, or API credentials.

Open `index.html` in a browser to preview. Push changes to `main` to publish.

## Publishing

GitHub Pages is configured to deploy from the root of the `main` branch.
The linked projects have their own repositories. This site presents those projects;
it does not run the dashboard's server-side integrations.
