# Patrick Taylor — Portfolio

Personal portfolio hosted at https://builtbyPat05.github.io/ using GitHub Pages.

## Edit

The website uses static HTML and CSS with no build step. `index.html` is the
landing page; `builder.html`, `creator.html`, `leader.html`, and `connect.html`
contain the detail pages. Shared styles live in the CSS files, including
`typography.css`, which loads the portfolio font. No API credentials are needed.

The [Creator Analytics project](https://builtbypat05.github.io/builder.html#creator-dashboard)
links to the [live Vercel dashboard](https://creator-dashboard-roan.vercel.app/)
and its [source repository](https://github.com/builtbyPat05/patsmemoir-creator-analytics).
The dashboard preview is stored in `assets/creator-dashboard.png`.

Open `index.html` in a browser to preview. Push changes to `main` to publish.

## Publishing

GitHub Pages is configured to deploy from the root of the `main` branch.
The linked projects have their own repositories. This site presents those projects;
it does not run the dashboard's server-side integrations.
